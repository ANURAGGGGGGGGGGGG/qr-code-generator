# QR Code Generator React App

A modern and user-friendly QR code generator built with React. Easily convert text/URLs into QR codes with real-time preview and download options.

## Features ✨
- **Custom QR Generation**: Input any text or URL to generate a QR code instantly.
- **Real-Time Preview**: See the QR code update dynamically as you type.
- **Download QR Code**: Save the generated QR as a PNG image.
- **Copy to Clipboard**: One-click copy functionality for quick sharing.
- **Responsive UI**: Works seamlessly on both desktop and mobile devices.
- **Error Handling**: Clear messages for invalid inputs.

## Installation ⚙️
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/qr-generator-react.git 
   ```

2. Install dependencies:
```
npm install
```

3. Run the development server:
```
npm start
```

## Usage 🚀
1. Enter text/URL in the input field
2. Watch QR code generate automatically.
3. Download button to save as PNG
